# Tarta 3D assets

`tarta.glb` is used for the interactive web viewer and Android AR. `tarta.usdz`
is the matching iOS Quick Look asset. Keep both files in this directory so
Next.js serves them as same-origin static assets on Vercel.

Replace both files together when updating the restaurant's model, and verify
that they depict the same dish and use matching real-world dimensions.
